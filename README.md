# Project Versel — Installers

Official **installer builds** for Project Versel. This repository holds nothing
but the released installer and this readme — the application source lives in a
private repository.

## Download

➡️ **[Download the latest installer](https://github.com/spokyishuman/ProjectVersel-Releases/releases/latest)**

Grab the file named `ProjectVersel.Setup.<version>.exe` from the newest release
and run it.

## Installing

1. Run the setup file. Windows may show a SmartScreen warning because the build
   is not code-signed — choose **More info → Run anyway** if you trust it.
2. Read and tick **"I accept the Terms and Conditions"** on the first page. The
   same page lists every permission the app needs.
3. Windows will ask for administrator approval **once** so the app can add a
   Windows Defender exclusion for the folder it patches. This is what stops your
   antivirus from deleting the files you asked it to place.

## Updating

Project Versel updates itself. Open **Settings → App Updates → Check for
updates**, and the newest installer from this repository is downloaded and
launched for you. You do not need to re-download manually.
